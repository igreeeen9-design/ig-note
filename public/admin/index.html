管理画面のセットアップ

この管理画面からGitHubリポジトリへ直接保存するため、アクセス用のトークンを一度だけ登録してください。トークンはこの端末のブラウザにのみ保存され、どこにも送信されません。

  1. GitHubで Settings → Developer settings → Personal access tokens → Fine-grained tokens を開く
  2. 「Generate new token」で、Repository access を「Only select repositories」→ ig-note のみを選択
  3. Permissions の Contents を「Read and write」に設定して発行
  4. 発行されたトークン(github_pat_...)を下に貼り付けて保存
