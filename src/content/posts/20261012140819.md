スマホ代を見直していた。  長年使ってきたドコモ回線も、もういいかなと思ってpovoへ。  携帯業界って昔から、長く使う人より乗り換えてくる人のほうが得だったりする。まあ、ドコモだけの話じゃないけど。  で、ふと思った。  俺、いつからドコモ使ってたんだ？  そこから、なぜか昔のケータイ探しが始まった。  ## 銀色のPHSの名前が出てこない  ドコモの前はPHSだった。  銀色で、アンテナが伸びて、ボタンのところにフタがあった。形はなんとなく覚えてる。でも機種名が出てこない。  昔の端末の写真を見ながら、  「違う」 「もっと丸かった」 「こんなんじゃない」  を繰り返し、ようやく見つけた。  京セラのPS-601。  たぶん。いや、かなりこれ。  こうなると次も気になる。家の中を探してみたら、まあ出てくる。  N209i。D505i。SO903i。Xperia。Huawei。ガラホまである。  よく取ってたな、俺。  せっかくなので机に並べてみた。ちょっとしたケータイ博物館である。  スマホ代を見直していただけなのに、気づけば30年近く前まで戻っていた。  ［ここに、発掘された端末を並べた写真］  ## 機種名は忘れるのに、待受は覚えている  N209iの待受は、「笑う犬の生活」のミル姉さん。  周りがカラー液晶に替えていくなか、自分だけまだ緑っぽい画面だったことも覚えている。なのに機種名は忘れていた。記憶って何なんだろうね。  D505iは逆に、待受が思い出せない。ただ、外側の小さい画面に通知が出て、開かなくても分かるのが便利だった。2003年ごろ、就職したての頃の相棒である。  SO903iの待受は、実家で飼っていた猫。  このケータイ、今見てもかなり変だ。いい意味で。外側に丸いボタンが並んでいて、閉じたまま音楽を操作できる。昔のソニエリ、よかったなあ。  今のスマホって、正面から見たらだいたい全部同じ。でもこの頃は、見ただけで「あ、NECだ」「三菱だ」「ソニエリだ」って分かった。  当時はわりと王道のラインナップだったはずなのに、今並べると結果的にだいぶ個性が強い。  そして気づいた。iPhoneが入る隙がない。Xperia、Huawei、またAndroid。どうやら最初からそっちのルートではなかったらしい。  で、「やっぱりSO903i、いいなあ」なんて触っていたら、  ボタンが取れた。  取れるんかい。  20年選手なので仕方ない。懐かしさに浸っていたところに、急に経年劣化を見せつけられた。  ## 私のケータイ遍歴(いまのところ)  また忘れそうなので、思い出せた範囲を残しておく。  | 時期 | 機種 | 覚えていること | |---|---|---| | 1996年ごろ | 京セラ PS-601 | 最初のPHS。銀色、アンテナ、ボタン部分にフタ | | 1998年ごろ | Panasonic P207 | ドコモ初期。ここは記憶ベース | | 2000年ごろ | NEC N209i | 待受はミル姉さん | | 2003年ごろ | 三菱 D505i | 外側ディスプレイの通知が便利だった | | 2006年ごろ | Sony Ericsson SO903i | 待受は実家の猫。今見てもデザインがすごい | | 2008〜2011年ごろ | Panasonic P-01A？ | たぶんこれ。現物は見つからず | | 2012年ごろ | Xperia AX SO-01E | 初スマホはたぶんこれ | | 2015年ごろ | Xperia J1 Compact | 楽天モバイルを使い始めた頃 | | 2018年ごろ | HUAWEI P20 lit
